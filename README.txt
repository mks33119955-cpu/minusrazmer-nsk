ВАЖНО:
Юридические страницы пока являются ЗАГЛУШКАМИ для тестирования навигации.
Перед публикацией заменить их финальными документами.

Для локального теста:
1. Распакуйте папку.
2. Откройте index.html в браузере.
3. Проверьте мобильную версию через инструменты разработчика.
4. Проверьте все кнопки, якоря, DIKIDI, телефон и юридические ссылки.
