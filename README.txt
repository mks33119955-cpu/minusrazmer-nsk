МИНУСРАЗМЕР — production-ready static site
Версия: v13 — обновлённая продающая структура

Состав:
- index.html — главная страница
- assets/logo.png — оригинальный логотип студии, без изменений
- assets/equipment-visual.png — дизайнерская визуализация оборудования; не является фотографией студии
- assets/hero-visual.png — эмоциональный первый визуал сайта
- privacy.html — политика конфиденциальности
- consent.html — согласие на обработку персональных данных
- offer.html — публичная оферта
- requisites.html — реквизиты ИП

Что обновлено в v13:
- первый экран явно позиционирует услугу как «LPG-массаж · Новосибирск»
- добавлен заголовок «LPG-массаж в Новосибирске»
- добавлен отдельный блок «Первый визит — можно начать с одной процедуры»
- сохранена возможность оплаты отдельной процедуры без покупки курса
- убран дублирующий блок «На что делаем акцент»
- в тарифах добавлена стоимость одной процедуры для прозрачного сравнения
- формулировки «Персональный формат» заменены на конкретное «Сопровождение по программе»
- улучшены canonical и Open Graph / Twitter meta
- НЕ добавлялись фальшивые отзывы, результаты и фотографии студии
- реальный блок фото студии и реальные отзывы можно добавить после получения материалов

Важно:
1. index.html лежит в корне.
2. Папку assets не переименовывать.
3. Для Vercel проект можно подключать как статический сайт без build-команды.
4. Публичный телефон студии: +7 (923) 742-15-57.
5. Юридические реквизиты указаны отдельно; банковские реквизиты в сайт не вынесены.
6. Ультразвук и миостимуляция не используются и не рекламируются.
7. «Формульная диетология» описана как практические рекомендации по питанию, не как медицинская помощь.
8. Визуализация аппарата помечена как дизайнерская, чтобы не выдавать сгенерированное изображение за фотографию конкретного оборудования.
9. Перед публикацией юридических документов рекомендуется финальная проверка юристом.
